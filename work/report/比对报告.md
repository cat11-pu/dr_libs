# dr_libs 解码器三方参考比对报告

- 被测对象：`dr_wav` / `dr_flac` / `dr_mp3`（仓库 `f12e197`，单头文件版本）
- 参考解码器（相互独立、均为系统打包版本）：
  - WAV → libsndfile 1.2.2
  - FLAC → libFLAC 1.5.0
  - MP3 → libmpg123 1.33.3
- 测试机：Ubuntu 26.04，gcc 15.2，ffmpeg 8.0.1，16 核
- 测试时间：2026-11-13

## 一、结论摘要

| 测试项 | 规模 | 结果 |
| --- | --- | --- |
| 合法文件逐样本比对（解码阶段） | 10,000 | 全部一致，0 失败 |
| 合法文件逐样本比对（seek 阶段） | 10,000 | 全部一致，0 失败 |
| 畸形文件错误判定 | 1,000 | 848 一致 + 68 更严格 + 84 更宽松 |
| 长循环内存稳定性 | 100,000 轮 / 30 万次解码 | 0 泄漏，峰值 64 KiB（追踪口径） |
| ASan+UBSan（合法 + 1,000 畸形） | — | 0 报错 |

合法语料上 dr_libs 与三个参考解码器**逐位一致**（MP3 为有损格式，按 dr_libs
官方测试框架口径使用 ±2 s16 单位容差，见 `tests/dr_libs_test_mp3.c:135`）。
畸形语料上 91.6% 的判定与参考一致或更严格；84 个文件 dr_libs 比参考宽松，
清单见下文第三节，均不涉及内存安全问题。

## 二、合法语料（10,000 个文件）

### 语料构成（ffmpeg 独立合成，确定性种子）

| 格式 | 数量 | 覆盖维度 |
| --- | --- | --- |
| WAV | 4,000 | pcm_s16le / s24le / s32le / f32le，单/双声道，7 种采样率（8k–48k） |
| FLAC | 3,000 | 16/24-bit，压缩级 0–8，单/双声道，7 种采样率 |
| MP3 | 3,000 | 64/96/128/192/256/320 kbps，单/双声道，7 种采样率 |

信号源在正弦波（330/880/120 Hz，含 beep）、白/粉/棕噪声间轮换，时长
1.0–5.8 秒。FLAC 32-bit 未覆盖：ffmpeg 8 原生 FLAC 编码器上限为 24-bit，
请求 s32 会被静默截断为 24-bit，已在生成脚本注释说明。

### 比对方式与结果

- 比对器：仓库自带 `tests/dr_libs_test.c`，WAV/FLAC 走 `memcmp` 逐位比对
  （`dr_libs_test_wav.c:272`、`dr_libs_test_flac.c:310`），MP3 逐样本求最大
  绝对差并以容差 2 判定（`dr_libs_test_mp3.c:135,257`）。
- 解码阶段：`Decoding: 0 failed`，10,000/10,000 通过。
- Seek 阶段：`Seeking: 0 failed`，10,000/10,000 通过。
- 原始日志：`report/valid_stdout.log`、`report/valid_seek_stdout.log`，
  两个 stderr 日志均无错误行。

## 三、畸形语料（1,000 个文件）

### 语料构成

从合法语料按确定性种子（`0x35572026`）派生：WAV 400、FLAC 300、MP3 300。
六类变异：截断、头部覆写、位翻转、区间清零、同格式片段拼接、尾部追加。

### 判定口径

对每个文件同时驱动 dr_libs 与对应参考库，记录 open / 产出任意帧 /
完整无错解码三个阶段。仅当某库完整到达流末尾且无硬错误时记为"接受"。
- 双方都拒绝 → 一致（拒绝发生在 open 还是 decode 阶段不影响结论）；
- dr 拒绝、参考接受 → 更严格；
- dr 接受、参考拒绝 → 不一致（dr 更宽松）。

### 总体结果

| 格式 | 总数 | 一致 | 更严格 | 更宽松（不一致） |
| --- | --- | --- | --- | --- |
| WAV | 400 | 396 | 3 | 1 |
| FLAC | 300 | 207 | 51 | 42 |
| MP3 | 300 | 245 | 14 | 41 |
| 合计 | 1,000 | 848 | 68 | 84 |

满足"错误判定与参考一致或更严格"的比例为 916/1000 = 91.6%。

### 84 个不一致（dr 更宽松）按参考库错误归类

| 数量 | 参考库报错 | 含义 |
| --- | --- | --- |
| 40 | mpg123：resync 超限找不到有效 MPEG 数据（code 28） | dr_mp3 跳过坏帧继续解码 |
| 39 | libFLAC：`LOST_SYNC` | dr_flac 重新同步后跳过坏帧继续 |
| 1 | libFLAC：元数据读取失败 | dr_flac 容错恢复并解出音频 |
| 1 | libFLAC：元数据阶段零帧失败 | 同上的极端情形 |
| 1 | libFLAC：MD5 校验不匹配 | dr_flac 不校验音频 MD5 |
| 1 | mpg123：返回 PCM 帧数多于 dr_mp3 | 帧计数口径分歧 |
| 1 | libsndfile：缺少 `data` chunk 标记 | dr_wav 仍按长度解出全部帧 |

按变异类型：拼接 20、清零 18、截断 16、头部 13、追加 9、位翻转 8。

### 不一致清单

- 机器可读全量清单（84 行，含格式/变异/参考错误/路径）：
  `report/inconsistencies_categorized.ssv`
- 探针原始七列行为矩阵（1,000 行）：`report/malformed_full.ssv`
- 分类汇总：`report/inconsistencies_breakdown.txt`

代表性案例（均已用官方 `dr_libs_test` 框架复核）：
- `corpus/malformed/wav/00255_01788.wav`：data chunk 标记损坏，libsndfile
  拒绝打开，dr_wav 完整解出 147,200 帧。
- `corpus/malformed/flac/00016_00116.flac`：区间清零，libFLAC 报 LOST_SYNC
  中止，dr_flac 解出剩余帧。
- `corpus/malformed/mp3/00000_00003.mp3`：头部变异，mpg123 resync 失败，
  dr_mp3 继续解码。
- `corpus/malformed/flac/00261_01831.flac`：追加数据导致解出音频与 STREAMINFO
  中 MD5 不符，libFLAC 报错而 dr_flac 无 MD5 校验环节。

根因均为设计取向差异：dr_libs 采用"跳过损坏、尽量产出音频"的容错策略，
参考库在同步丢失/校验失败时硬中止。未发现 dr_libs 崩溃、越界或内存问题。

## 四、长时间循环解码内存稳定性

### 追踪分配器（`work/mem_loop.c`）

三个解码器的全部 malloc/realloc/free 经带 8 字节头的计数包装器，逐轮
open → 全量 decode → close，每轮处理 WAV+FLAC+MP3 各一个文件。

100,000 轮（共 200,000 次跟踪分配，50 秒）：

```
iter=25000  live_allocs=0 live_bytes=0  total_allocs=50000
iter=50000  live_allocs=0 live_bytes=0  total_allocs=100000
iter=100000 live_allocs=0 live_bytes=0  total_allocs=200000
peak_live_bytes=65536 decode_failures=0
```

各检查点存活分配/字节相对第 1 轮增量恒为 0，无单调增长，峰值恒定 64 KiB。
外部观测（`/usr/bin/time -v`，50,000 轮）：最大 RSS 2,188 KB，
主缺页 0、次缺页 95。

### Sanitizer

- ASan+UBSan 构建跑 10,000 轮合法文件循环：退出码 0，无 leak/越界/UB 报告。
- ASan 构建对全部 1,000 个畸形文件各完整解码一次：退出码 0，0 条 ERROR
  （`report/malformed_asan.log`，日志中的 Rewinding/Bitreader 字样为
  libFLAC 自身诊断输出，非 sanitizer 报告）。

## 五、复现方式

所有产物在 `work/` 下，参考库以 `apt-get download` 免 root 解包到
`work/prefix`（无 sudo 环境），环境变量见 `work/env.sh`。一键复现：

```
cd work && source env.sh && bash run_all.sh
```

关键脚本：
- `gen_valid.sh` / `gen_malformed.py`：语料生成（确定性，可重复）
- `malformed_probe.c` + `analyze_malformed.py`：畸形行为采集与判定
- `categorize_malformed.py`：不一致分类（RNG 重放已与生成器逐调用对齐校验）
- `mem_loop.c`：内存稳定性 harness（普通版 + ASan 版）
